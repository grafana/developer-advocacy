Still using handmade manual dashboards, or are we moving towards more AI-based solutions? I will start with Carl. What do you still prefer?

**Carl:** Oh, I mean, it's not about preference. It's about getting the work done for me. AI is just faster for me. Every now and then, I might go tweak a setting because I know where it is. But if I want to build something bigger or more panels, then AI just does it faster for me. Building dashboards has never been fun. It's never been about using dashboards; it's about viewing them, looking at the data, and understanding the data. So yeah, that's just something that I want to be done with as soon as possible.

**Merle:** You have a lot of experience, especially coming from the ASF side. You've probably seen tons of dashboards as well. What do you prefer, AI or do you want to stick to the originality?

Well, it depends. If I'm talking with somebody else about a shared view of a problem, like we have dashboards that cover how frequently PRs are merged and how long it takes for PRs to merge, as well as dashboards that cover some of our internal processes. For that, it's actually very useful to have a shared set of assumptions about how to measure something, and a dashboard can capture that. But if I'm asking a question that it doesn't matter if I have a permanent answer to, where I'm just asking it in the moment, then I definitely prefer AI. Why would I want to craft a dashboard that I'm not going to pass off to anybody? So it depends; it can be either one.

**Carl:** Nice. Yeah, I agree. I think with AI, we can really save a lot of time instead of crafting anything handmade, which is, I mean, preference also, at least in my opinion. But AI definitely can do much better, much quicker.

**Dan:** Maybe you can add some more words and then share what you have prepared with us as well.

Sure! Yeah, so definitely my preference is to start with an AI-generated dashboard. I think that especially if you have something big in mind, it takes a long time to add lots and lots of panels. I also find AI to be a helpful thought partner when thinking about what the best visualizations are to understand the data that I'm looking at. But then once I've got an outline of the dashboard that I want, I often find myself tweaking the details by hand because it can be so much easier to just drag a panel than to ask the agent to move it left and things like that. So that's how I work, and I found it essentially a healthy balance of both.
