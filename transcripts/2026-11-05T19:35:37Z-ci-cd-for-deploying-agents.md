# CI/CD For Deploying Agents

Published on 2026-11-05T19:35:37Z

## Description

Continuous Integration and Continuous Delivery for Deploying Agents in Grafana Cloud is beneficial in two key areas; Agent Observability Experiments allows you to test your Agent offline before you bring it into production.  With Agent Observability Evaluations, you can do the same thing online, allowing you to see how your Agent behaves with your users and your applications as they correlate across the full stack.  You can then use these test cases to iterate on your prompt, harness, or Agent.  Watch fellow Grafanista, Jack provide a comprehensive deep dive walkthrough how to leverage this helpful new feature.
