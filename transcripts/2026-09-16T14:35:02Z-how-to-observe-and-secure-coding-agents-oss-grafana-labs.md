**Observe and Secure Your Coding Agents with Grafana**

Observe and secure your coding agents, such as Cursor and Cloud Code, with Grafana. Install the agent, Ollie, with a single command. Everything stays local, and it just works with the most popular coding agents, including Cursor, Cloud Code, Codex, and Pie.

It provides an overview of all your sessions, with analytics on token usage and costs broken down by workspace, branch, or project. With guardrails, you can redact secrets and block potentially harmful actions, such as reading or editing your `.env` files or running dangerous commands.

Coding agent observability is local, open source, and built to help you observe and secure your coding agents with Grafana.
