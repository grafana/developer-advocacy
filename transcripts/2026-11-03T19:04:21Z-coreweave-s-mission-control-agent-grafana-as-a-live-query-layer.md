# CoreWeave's Mission Control Agent: Grafana as a Live Query Layer

Published on 2026-11-03T19:04:21Z

## Description

CoreWeave's Mission Control Agent answers operational questions by investigating live observability data from Grafana, Prometheus, and Loki. Savio Dsouza of CoreWeave explains the investigation loop behind it: an agent harness that plans and coordinates investigations, an MCP server with scoped tools for gathering evidence, and verification steps that link findings back to Grafana dashboards. A demo follows the agent as it diagnoses a slow inference deployment, applies a fix, and validates the result. The session ends with lessons on designing tools for agents and making their evidence easy to inspect.
