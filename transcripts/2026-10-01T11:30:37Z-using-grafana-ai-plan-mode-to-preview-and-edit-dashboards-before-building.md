## Summary

The community call titled "Using Grafana AI plan mode to preview and edit dashboards before building," published on October 1, 2026, featured discussions on the new plan mode feature in Grafana. The speaker explained how this feature allows users to preview and edit dashboard panels before finalizing their builds, streamlining the dashboard creation process. Key takeaways include the ability to shape the dashboard plan interactively, ask questions about specific metrics, and make adjustments to titles, layouts, and visualizations before committing to the final build. This approach enhances user experience by reducing the time spent on corrections after the initial dashboard is created.
