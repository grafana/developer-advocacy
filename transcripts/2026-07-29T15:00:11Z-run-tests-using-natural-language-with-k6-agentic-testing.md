## Summary

In the video titled "Run tests using natural language with k6 Agentic Testing," published on July 29, 2026, Mat Ryer, Senior Director for AI Engineering at Grafana Labs, discusses the capabilities of k6 agentic testing in Grafana Cloud. The demonstration showcases how users can create tests using natural language, exemplified by a test for the game Wordle, where the system successfully navigates the game autonomously. Key takeaways include the potential for high-level, ambiguous language in testing scenarios, which can be beneficial for certain types of tests. The session highlights the innovative use of AI in simplifying the testing process.

Topics: k6, agentic testing, Grafana Cloud, natural language processing, Wordle.
