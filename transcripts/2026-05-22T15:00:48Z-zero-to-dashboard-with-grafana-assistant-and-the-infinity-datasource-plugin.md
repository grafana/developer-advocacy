## Summary

The show "Zero to Dashboard with Grafana Assistant and the Infinity datasource plugin" was published on May 22, 2026, featuring Senior Developer Advocate Nicole van der Hoeven. In this session, she demonstrated how to quickly create a dashboard using Grafana Assistant and the Infinity data source plugin, utilizing data from the RAWG API to visualize Nintendo games. Key takeaways included the ease of setting up a dashboard without needing to learn multiple query languages, the ability to customize visualizations, and the Assistant's capability to provide personalized game recommendations based on user queries. 

Topics: Grafana Assistant, Infinity datasource, RAWG API, dashboard creation, data visualization.
