# AI Week: Monday announcements

## Description

AI Week has begun! Check out grafana.ai for more details on what we've announced and what else is coming out today.

URL: https://www.youtube.com/watch?v=AEU73mjeh0c

## Summary

The show is titled "AI Week: Monday announcements," published on July 27, 2026. The speaker, Nicole Vanderhoeven, introduces new features related to Grafana Assistant. Key announcements include a new full-page view for the Assistant, which allows for easier navigation and investigation, as well as enhanced accessibility for users by enabling the Assistant in Grafana 13 without needing to link a Grafana Cloud account. Additionally, users can now try Grafana Assistant on Grafana Play without any sign-up or download required. 

Topics: Grafana Assistant, Grafana 13, Grafana Play, user accessibility, AI Week.

[music] 

Hi everyone, I'm Nicole Vanderhoeven, and I'm really excited to welcome you to **AI Week**. Today is Monday, which is planning day, where we give you the tools you need to get clarity on what is going on in your system, so you can figure out what to build.

Now, we're kicking things off with a feature called **workspace for Grafana Assistant**. If you've used Assistant before, then you'll know that it appears in the little right sidebar on Grafana. However, that can start to get cramped if you have multiple conversations or if you've asked Assistant to generate multiple graphs for you. We've heard your feedback, and now we're giving you a full page view of Assistant. You'll have all of your conversations on the left, and this is also an excellent place to run investigations from. You can zoom in on any of those graphs, and it's just a much less cluttered view if you want to be agent-first.

Speaking of Assistant, the second thing I want to tell you is that Assistant was already available everywhere, but now it's available in more places than ever and also more easily. Assistant was previously available for OSS, but you had to link your Grafana Cloud account, which was not very handy if you wanted to try it out. But not anymore! Now, if you download Grafana 13 and enable Assistant, you'll be able to try it out and chat with Assistant without doing anything else. It's still not free or open source, but it is a lot easier to try it out.

If you don't want to download anything, that's what **Grafana Play** is for. Grafana Assistant is now available to try out on Grafana Play without any sign-up or download required. You can try it out at [play.grafana.org](http://play.grafana.org). I really love seeing it there.

Tune in tomorrow, where we're going to talk about everything that we're announcing to help you start to build.
